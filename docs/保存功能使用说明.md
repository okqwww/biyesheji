# 题目保存功能使用说明

## ✅ 功能概述

已成功实现题目保存到 Neo4j 数据库的功能，可以将生成的题目与知识点建立关联并持久化存储。

---

## 🎯 功能特性

### 1. 智能保存
- ✅ 保存题目完整信息（题干、选项、答案、解析、评分标准）
- ✅ 自动关联选中的知识点
- ✅ 记录创建时间和来源标记（ai_generated）

### 2. 状态管理
- ✅ 保存中显示 Loading 状态
- ✅ 保存成功后按钮变为绿色"已保存"
- ✅ 重复保存需要二次确认
- ✅ 重新生成题目后重置保存状态

### 3. 错误处理
- ✅ 无题目时提示"暂无题目可保存"
- ✅ 缺少知识点信息时提示错误
- ✅ 保存失败时显示友好提示

## 📝 使用流程

### Step 1: 生成题目
1. 在知识图谱页面选择知识点
2. 配置题型、难度、数量
3. 点击"生成题目"
4. 等待题目生成完成

### Step 2: 查看题目
1. 跳转到题目结果页
2. 检查题目内容是否满意
3. 如果不满意，可以点击"重新生成"

### Step 3: 保存题目
1. 点击**"保存"**按钮
2. 看到提示："正在保存..."
3. 成功后显示："成功保存 N 道题目"
4. 按钮变为绿色**"已保存"**

### Step 4: 重复保存
- 如果再次点击"已保存"按钮
- 会弹出确认对话框："题目已保存过，是否重复保存？"
- 点击"保存"继续，点击"取消"放弃

## 💾 数据保存内容

### 保存到 Neo4j 的数据

```cypher
// 题目节点
(:Question {
  id: "uuid-xxx",
  type: "single_choice",  // 题型
  difficulty: "medium",    // 难度
  content: "题干内容",
  options: ["A. ...", "B. ..."],  // 选项（JSON字符串）
  answer: "B",             // 答案
  explanation: "解析内容",
  scoring_points: [...],   // 评分标准（解答题）
  created_at: "2026-01-04T15:00:00",
  source: "ai_generated"
})

// 关系
(Question)-[:TESTS]->(KnowledgePoint)
```

### 请求数据格式

```json
{
  "questions": [
    {
      "type": "single_choice",
      "difficulty": "medium",
      "content": "题干",
      "options": ["A. 选项1", "B. 选项2"],
      "answer": "B",
      "explanation": "解析",
      "knowledge_points": ["for循环", "列表"]
    }
  ],
  "knowledge_point_ids": [
    "py_kp_for_loop",
    "py_kp_list"
  ]
}
```

## ⚠️ 注意事项

### 1. 知识点信息必须存在
- 保存时会校验 `knowledge_point_ids`
- 如果知识点ID不存在，保存会失败
- 确保题目是从知识图谱页面生成的

### 2. 保存是永久性的
- 保存到数据库后无法撤销
- 只能通过数据库管理工具删除
- 建议先导出备份，再保存

### 3. 可以重复保存
- 同一批题目可以多次保存
- 每次保存会生成新的题目ID
- 不会覆盖之前保存的题目

### 4. 重新生成会重置状态
- 点击"重新生成"后，保存状态重置
- 新生成的题目需要重新保存
- 之前保存的题目不受影响

## 🐛 常见问题

### Q1: 点击保存后没反应？
**检查**：
1. 浏览器控制台是否有错误
2. 后端服务是否正常运行
3. Neo4j 数据库是否连接成功

**解决**：
- 刷新页面重试
- 检查后端日志
- 验证 Neo4j 连接

### Q2: 提示"缺少知识点信息"？
**原因**：题目不是从知识图谱页面生成的，或页面刷新后状态丢失

**解决**：
1. 返回知识图谱页面
2. 重新选择知识点
3. 重新生成题目

### Q3: 保存成功后如何查看？
**方法1**：使用 Neo4j Browser
```cypher
// 查看最近保存的题目
MATCH (q:Question)
WHERE q.source = 'ai_generated'
RETURN q
ORDER BY q.created_at DESC
LIMIT 10
```

**方法2**：查看题目与知识点的关联
```cypher
// 查看题目关联的知识点
MATCH (q:Question)-[:TESTS]->(kp:KnowledgePoint)
RETURN q.content, kp.name
LIMIT 10
```

### Q4: 保存失败怎么办？
**常见原因**：
1. Neo4j 连接断开
2. 知识点ID不存在
3. 数据格式错误

**解决方法**：
1. 检查 Neo4j 是否运行
2. 查看后端终端日志
3. 尝试重新生成题目
4. 如果持续失败，先导出为 Markdown

## 📊 与导出功能对比

| 功能 | 保存到数据库 | 导出为Markdown |
|------|-------------|---------------|
| **用途** | 持久化存储，建立关联 | 文件备份，离线使用 |
| **优点** | 可查询、可统计、可复用 | 便于分享、编辑、打印 |
| **缺点** | 需要数据库支持 | 无法直接查询 |
| **建议** | ✅ 重要题目建议保存 | ✅ 所有题目建议导出 |

**最佳实践**：
1. 先导出为 Markdown（备份）
2. 再保存到数据库（持久化）
3. 这样既有备份，又便于查询
