## 🐛 快速排错

### 问题：后端提示"ModuleNotFoundError"

```powershell
# 重新安装依赖
cd G:\biyesheji\backend
.\.venv\Scripts\activate
pip install -r ../requirements.txt
```

### 问题：Neo4j 提示"连接失败"

```powershell
# 检查 Neo4j 是否运行
# 方法1：查看是否有 Neo4j 进程
tasklist | findstr java

# 方法2：尝试访问 http://localhost:7474
```

### 问题：前端白屏

```powershell
# 打开浏览器 F12 查看控制台错误
# 通常是后端未启动或端口错误
# 检查 vite.config.js 中的 proxy 配置
```

### 问题：题目生成失败

**检查清单**：
1. 后端是否成功启动？
2. DeepSeek API Key 是否正确？
3. 网络是否能访问 api.deepseek.com？
4. 查看后端终端的错误日志

## 📖 开发提示

### 修改代码后如何生效？

| 修改内容 | 是否需要重启 |
|---------|-------------|
| 前端代码 (.vue, .js) | ❌ 不需要（热重载） |
| 后端代码 (.py) | ❌ 不需要（DEBUG=true时自动重载） |
| .env 配置文件 | ✅ **必须重启后端** |
| package.json | ✅ 需要重新 npm install |
| requirements.txt | ✅ 需要重新 pip install |

### 如何查看当前使用的配置？

```python
# 在后端代码中查看
from app.core.config import settings
print(settings.DEEPSEEK_API_KEY)  # 查看当前API Key
print(settings.NEO4J_URI)  # 查看数据库连接
```

## 🎯 测试系统的最快方式

启动系统后，按这个流程快速验证：

1. **访问首页** (http://localhost:5173)
   - 点击"开始使用"

2. **选择课程**

3. **生成题目**
   - 点击 3 个知识点
   - 题型选"单选题"
   - 数量选"2"

4. **查看结果**
   - 等待 10-15 秒
   - 看到 2 道题目
   - 包含题干、选项、答案、解析

**总耗时**：< 2 分钟
