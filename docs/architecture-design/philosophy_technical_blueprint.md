# Technical Blueprint

A dark, technical drawing aesthetic that evokes engineering blueprints and circuit schematics. The architecture floats in deep navy darkness like a blueprint exposed on a light table. Each layer rendered with surgical precision—thin annotation lines, exact measurements, crosshair references. Typography is monospace throughout, suggesting code and technical specification. Color palette drawn from midnight blue, electric cyan for accents, and warm amber for the AI/LLM component. The design communicates: this is engineered, not generated. Every connection is intentional, every boundary defined.
