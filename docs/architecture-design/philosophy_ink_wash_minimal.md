# Ink Wash Minimal

A refined Japanese aesthetic inspired by traditional sumi-e (ink wash) painting and wabi-sabi philosophy. The architecture appears as brush strokes on rice paper—organic, impermanent, gracefully imperfect. Each node is rendered not as a box but as a suggestion, a gestural mark. Typography is delicate, slightly irregular, hand-drawn in feeling. Color is restrained to black ink tones with a single seal red accent. The whitespace is active, not empty—it breathes and frames. This is not a diagram but a meditation on structure and flow.
