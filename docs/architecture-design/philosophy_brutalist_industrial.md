# Brutalist Industrial

A raw, industrial aesthetic inspired by brutalist architecture and concrete structures. The architecture appears as monumental forms rising from textured concrete—heavy, permanent, undeniable. Typography is bold and imposing, treatment as structural elements. Color is restrained: concrete grey, rust orange, steel blue. No rounded corners, no gradients, no subtlety. This is honest materiality rendered digitally. The message: this system is solid, built to last.
